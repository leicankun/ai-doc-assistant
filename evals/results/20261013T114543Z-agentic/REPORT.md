运行开始：2026-10-13 19:45（北京时间）。结果目录：`20261013T114543Z-agentic`。

## 结果解释

Agent 固定要点完整通过数增加 5 题，平均聊天 token 为普通 RAG 的 16.6 倍；优势主要集中在完整上下文与综合题，不能据此认为所有问题都应该走 Agent。

- rag 正确拒答行为：4/4（100.0%）；这与要求额外解释全部匹配的固定要点通过数不同。
- agent 正确拒答行为：3/4（75.0%）；这与要求额外解释全部匹配的固定要点通过数不同。
- Hybrid 不重排 / 重排的完整依据覆盖分别为 15/24 与 15/24；本次运行没有表现出重排的完整依据覆盖收益，不写成重排提升准确率。
- 12 个分块只含标题；8 个单轮 Agent 成功响应触发上下文省略。这是分块和上下文分配需要改进的具体线索。
- 对 91 个成功回答、217 个引用进行编号与原文身份核对，发现 0 个身份不一致项。这只验证来源身份，不等于事实语义支持。

## 可用于简历的表述

构建覆盖 12 份文档、87 个分块的 30 题固定评测集，使用真实模型对照普通 RAG 与 Agentic RAG，在同模型自动评审下，任务通过数分别为 19/30 与 24/30；补充检索重排消融、引用支持度及多轮条件纠正测试，并记录实际 token 用量与 P50/P95 耗时。
