# 助手复核备注

本备注由完成评测的同一助手检查差异及扣分案例后记录，不是独立人工评分。
原始答案、预设要点、自动评审 JSON 和通过计数均保留，不用这些备注覆盖原始分数。

## 自动评分的已知问题

- **a022 / rag**：回答确实写出“P95 超过 800 毫秒并持续 5 分钟”，但自动评审把第一个
  对应要点判为 false。该题仍缺磁盘阈值和解除条件，因此整体未通过不变，平均要点覆盖受此误判影响。
- **a027 / 两种方法**：都正确说明资料没有恢复时限保证，且没有编造数值；自动评审因未说
  “不能把演练频率当作 RTO”而判整体未通过。该额外解释不是用户明确要求，固定要点完整通过
  比常规正确拒答更严格。正确拒答应另观察 `behavior_correct`，不能直接采用分类 `task_pass`。
- **a030 / rag**：回答指出版本未明确，没有擅自选唯一配置，但没有直接问句，而且列出多个版本，
  不完全遵循用户“不列多个版本”的要求。自动评审给通过，对澄清与指令遵循较宽松。
- **a030 / agent**：回答在用户要求先确定版本时主动选择“若以最新 2.4 为准”给配置，
  澄清行为不理想；但自动评审另称 PostgreSQL 15 的引用不支持数据库结论，判断偏严。
  实际引文描述 PostgreSQL 15 是启动依赖且就绪检查验证数据库连接，可支持相应数据库类型/版本。
- 多个扣分记录把“缺少必要事实或部分拒答”也计作 `citation_errors`。这会混合证据完整性
  与已引用事实的支持度。通过数的口径已要求全部要点，所以不会因此多扣通过题，但单独引用指标
  不宜解释成纯粹的语义引用准确率。

因此主报告使用“固定规则同模型自动评分”，不把 19/30 与 24/30 称为独立验证的回答准确率。
下一版应在跑之前把评分拆成回答完整性、已回答事实支持度、行为正确性与指令遵循，
对拒答仅要求依据不足说明且不编造，而不强制额外解释；当前正式题集和原始分数不事后更改。

## 系统问题与原始证据

- **a006**：普通 RAG 缺 OIDC 与完整备份内容；Agent 补齐了备份，但认证正文仍未纳入最终证据。
- **a013、a019 / agent**：最终输出资料不足，并提示上下文预算省略；普通 RAG 在 a019
  已能答出回滚所需的数据库/附件、旧版健康检查和新版写入处理。Agent 并非每题都更好。
- **a026 / agent**：回答模型第二次聊天调用为真实 `APIConnectionError`，接口返回 502。
  两次检索与重排已成功，不能把它当作问题无法回答，也不能从通用 HTTP 错误文本推断密钥无效。
  没有用重新跑出的成功覆盖此次失败。
- 87 个分块中有 12 个仅包含文档标题。Top-K 中标题块占据名额，直接影响综合问题的依据覆盖。
  各配置命中标题块的计数见 `audit.json`。这提示分块与标题上下文处理值得优化，当前评测不修改生产实现。
- 单轮有 8 个 Agent 成功响应报告上下文预算省略了工具项。原始工具召回与实际模型上下文的
  依据覆盖需分开看，后者见 `context_evidence.jsonl`。

## 来源核对

`audit_agentic_benchmark.py` 对本次所有成功回答逐条核对引用编号、分块身份与原文内容。
具体数量与身份不一致项见 `audit.json`。这是程序化来源身份检查，不等同于语义支持度的独立审核。

运行开始时的 35 个 Python 源文件副本保存在 `code_snapshot/`，复制时逐个核对其哈希与
`metadata.json` 一致；没有复制 `.env` 或密钥。后续新增报告与核对脚本不改变本次已加载的评测代码。

## 多轮结果

32 轮请求全部成功，两个 Agent 会话都真实保存并增量更新了摘要，纠正后的条件仍存在于最终摘要。

- **环境纠正**：普通 RAG 失去早期 Windows 条件，最终列出多种命令且遗漏目录与热加载限制；
  Agent 记住 Windows 11 并正确给出命令与目录，但未补读 Windows 热加载例外，误答日志修改不需要重启。
  因此条件保留成功不等于最终问答成功，该目标题未通过。
- **版本纠正**：普通 RAG 无法确定实际维护版本，备份信息也未取全；Agent 通过摘要识别实际维护的
  Atlas 1.8，并重新检索给出 8100、/health、24 小时、7 天，目标题通过。

两组会话的目标题自动评分分别为普通 RAG 0/2、Agent 1/2。样本仅两个，不推算普遍记忆成功率。
全部 91 个成功回答的 217 个引用均通过编号、正文与分块来源身份核对；仍有环境纠正题的语义错误。
