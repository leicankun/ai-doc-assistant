# 分块对照复核说明

由实现和运行评测的同一助手检查原始检索结果、回答及评分后整理，不是独立人工评分。未改写原始模型输出、评分或固定标准。

## 可以支持的结论

- 原始 20 份带小节标题的文档，三种参数均逐块产生相同的 183 块，最长 178 字符。标题边界优先于长度参数，改变上限在这份原始结构上没有改变分块；不能把长章节结果描述成原始文档已获得同样提升。
- 同事实长章节版本中，`500＋100` 在当前预算下表现较均衡：test 集标注证据覆盖 97.66%，完整覆盖 30/32；`800＋160` 的 Top-5 覆盖为 100%，但平均输入正文从约 2052 字符增加到 2975 字符，2500 字符预算覆盖降为 91.67%。
- 20 题回答原始自动评分为 15/20、19/20、18/20。拆分行为后，三组实答题为 13/16、16/16、16/16；纯拒答均 2/2；澄清为 0/2、1/2、0/2。不能把 19 对 18 描述为已证明稳定的事实回答质量差距。
- 先保留当前生产 `500＋100`；这次评测不修改分块逻辑、索引或生产默认参数。结果不构成通用最优配置。

## 原始案例检查

### r019：小块缺少模型一致性要求

问题要求 Aster 新版维度和搜索/文档编码能否混用模型。300 组检索没有带回完整的“768维且同一模型版本”标注证据，回答从归档材料中提到 768 个分量，但加了推测，并称未提供能否混用模型的信息。500、800 均引用新版说明给出 768 维和同一模型版本要求。

评分器把 300 组两个答案点全判 false，对已经提到的 768 维可能偏严。即便将这一点计入，仍缺少“同一模型版本”，任务通过结论不变。保留原始分数，不将点覆盖分当独立人工准确率。

### r025：小块遗漏跨文档数据库版本

300 组答出了 E201 核对 database.url/网络与 /ready，但缺少 PostgreSQL 15，因此任务不通过；500、800 均覆盖三个预期要点。

500、800 的回答又额外称资料没有“E201修复后专用切流条件”，同时给出了通用 /ready 切流要求。自动评审按答案点通过，不代表这两段表述已完全理想。

### r045：标注证据覆盖与答案事实覆盖有差别

500 组标注证据覆盖为 75%，但答案和实际引文包含全部所问版本维度与文档上限。原因是预先 gold 将新版维度绑定到同时包含“同一模型版本要求”的完整新手册句子，而检索返回的旧版本对照段落已经明确给出“4.2使用768维”。

这是固定证据区间指标的局限，不能把 75% 直接解释为该答案只答对 75%。没有根据本次输出补写替代证据或改变固定题集。

### r057、r059：澄清行为仍有缺口

r057 未指定 Atlas 版本。500 组最后明确询问用户是哪一版本，300、800 只列出版本差异，没有实际发问。因此 19/20 与 18/20 的一题差异来自澄清动作，可能受单次生成波动影响。

r059 未指定 Aster 标准版或企业版，三组都给出两个数值，却没有询问订阅类型，按照固定 clarify 标准均不通过。不是数字错误。

## 控制变量和限制

- 修改的是小节标题标记，不修改正文事实或同一文档内的顺序。所有问题和答案点保持不变；证据字符区间按新正文重新定位。原始和长章节必须分开解释。
- 候选数固定的是上限 30。300、500 实际都召回 30 项；800 总共只有 22 块，因此实际候选为 22。三组长章节候选池对 test 集的标注证据覆盖均为 100%，结果差异主要发生在后续排序和 Top-5 筛选。
- 800 几乎将短手册整篇作为一个块，不足以代表数万字文档。资料仍是合成运维规则，20 份文档、一次运行，未做置信区间或多轮重复。
- 大块 Top-5 输入更多正文；等预算指标只对原 Top-5 做完整块装箱，不重新按预算优化候选选择，也没有运行 Agent 的实际预算算法。
- 500 与 800 在 20 题中的回答输入 token 总数分别为 34671 和 46493。它们是相同问题集上本次供应商真实 usage，不是固定收费或普遍节省比例。
- 真实调用共 36 次 Embedding、240 次 Rerank、160 次 Chat（80回答＋80评分），均成功。原始完整响应与 usage 保留于 calls.jsonl；没有为得到通过结果重跑覆盖失败。
- 确定性审计核对 240 次检索、80 次回答和 162 个引用，未发现布局、指标、MMR重放、来源身份或快照哈希不一致。该核对不证明引文语义支持每句话。
- 正式 MySQL 全表、旧 SQLite、上传文件和持久化 Chroma 的运行前后指纹一致。评测只写临时 SQLite 和内存 Chroma，不新建正式文档或重建正式向量。

新增评测器离线检查 5 项通过；当前完整回归共 184 项，176 项通过、8 项依赖独立 MySQL 测试配置而跳过。跳过项不计为通过。
